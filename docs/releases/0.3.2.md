# Square 0.3.2

Square 0.3.2 是从 `main` 发布的维护版本。框架与模板仍为 22 个统一版本的 `Wuldas.Square` / `Wuldas.Square.*` 包，面向 .NET 10。本版本合并了 CI 恢复、Issue #16–#24 的修复，以及模板、flex 布局与字形回退的剩余问题；没有新的 Canvas 性能基准声明，也没有新增生产语言服务器功能。

## 主要修复

- **CI 恢复**：X11 / macOS 的 TreeItem header 像素取整断言按设备像素网格容差判定；Win32 Direct2D conformance 截屏等待两帧稳定后再比较，消除 DWM 合成时序造成的偶发失败。
- **Issue #16–#24**：
  - 条件渲染：`v-if` / `v-else-if` 链订阅组件属性变化并重新求值，组件模板根 `v-if` 生效。
  - 绑定/编译：字面量 `:prop` 生成 CLR 属性直接赋值，单表达式插值走 `BindText`，集合属性绑定可编译，并文档化 `BindProperty` 不调用 CLR setter 的语义。
  - 事件：带参处理器生成回调 lambda，`.stop` / `.prevent` 不再强制 `Event` 签名，新增 `SetPointerCapture` / `ReleasePointerCapture`。
  - 布局：flex/grid 路径下 `position: fixed` 按视口布局，空 auto 高度元素不占主轴空间。
  - 指针坐标：宿主鼠标事件与 DevTools 注入携带真实 `ClientX` / `ClientY`。
  - Input：单行输入按 Enter 提交 `change`。
  - DevTools：loopback 监听失败时降级而不终止应用；生成代码落盘开关在 buildTransitive targets 生效。
- **模板、布局与文本**（PR #26）：修复剩余模板与 flex 布局问题；新增字体回退配置与测试；中文字符间距、小字形整像素对齐、亚像素笔画亮度、ASCII 间距与裁剪标签下缘等多处排版稳定性修复；软件渲染圆角边框无缝拼接与文本基线对齐。

## 源码与性能边界

相对 `v0.3.1` 的源码树包含上述功能与修复，不应视为逐字节相同的维护补丁。README 中的 0.3.0 表格及 [2026-11-11 测量记录](../benchmarks/2026-11-11.md)保留原版本、样本与口径，不宣称为 0.3.2 新测结果。Canvas 与软件呈现的功能说明见 [0.3.0 发布说明](0.3.0.md)，其中 best-effort DWM 同步和原生桌面截图 **0/2、limited** 的已知限制继续有效。

## 发布验证与升级

0.3.2 的版本提交先进入 `main` 并通过 CI（Win32 / X11 / macOS / IDE tooling）与 Android 工作流，再创建匹配版本标签。正式发布工作流只接受 `main` 已有提交，且标签版本必须与 `Directory.Build.props` 的 `Version` 一致；手动 workflow_dispatch 仍只构建验证，不发布。旧 0.3.0 / 0.3.1 包和公开标签保持原样，不覆盖或移动。

现有应用应将框架、编译器、平台、后端和扩展包统一升级至 0.3.2。安装模板：

```bash
dotnet new install Wuldas.Square.Templates@0.3.2
dotnet new square -n MyApp
dotnet run --project MyApp
```

完整安装与平台边界见[入门指南](../Getting-Started.md)。项目仍处于实验阶段，公共 API 与模板语法可能继续调整。
