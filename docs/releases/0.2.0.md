# Square 0.2.0

Square 0.2.0 是以性能优化为主的版本，重点降低代码编辑器分词缓存、跨区回跳，以及布局、动画和绘制路径的 CPU 与分配开销。发布 22 个统一版本的 `Wuldas.Square` / `Wuldas.Square.*` 框架及模板包，面向 .NET 10。项目仍处于实验阶段，公共 API 和模板语法可能继续调整。

## 性能优化

- 代码编辑器使用内置 SortedList 二分定位检查点，按需剪枝，去掉热命中的全量检查点扫描及分配。
- 过渡行只推进状态，减少逐行字典写入和修剪；旧缓存窗口保留至批次结束，避免重复分词。
- 固定 1024 个非零检查点预算内保留稀疏全局恢复点与目标附近密集点，减少大文件旧区域回跳时从头重算。
- 降低布局、CSS 动画、绘制与局部失效路径开销，完善跨框架性能比较及计时回归。
- 分词缓存新增跨行状态、EOF、失效、容量、异常恢复和全局保留策略测试；完整代码编辑器套件 190 项通过。

## 发布与配套

模板与框架依赖统一为 0.2.0，模板验证从根版本读取包文件名。发布回归中功能测试和计时敏感测试分开执行；工具链加密依赖升级至安全补丁版本，内存诊断对 GC 期间的近似负值采样做非负归一化。现有静态 HTML、DevTools、Direct2D/DirectWrite 等能力继续随对应包提供，使用方式见仓库文档。

## 分词缓存测量

在 i5-12400F、Windows、.NET 10.0.11 的百万行混合 C# 文本上，对比本轮全局保留策略与前阶段已经优化的缓存：

| 场景 | 前阶段/ms | 0.2.0/ms | 重新分词行数 |
|---|---:|---:|---:|
| 真实 TextMate 回跳至第 8,192 行 | 1,727.7 | 434.2 | 8,192 → 2,048 |
| 合成分词器回跳文档中部 | 40.94 | 0.0285 | 500,000 → 288 |
| 合成分词器文档中部失效重读 | 33.13 | 0.0387 | 500,065 → 353 |

真实与合成分词器的结果不能相互替代。以上是指定分词轨迹的样本中位数，不是 UI 帧时间；全局检查点只覆盖已成功扫描且未被失效删除的状态，首次加载仍需建立跨行状态。完整数据与复现方法见[检查点报告](../../tools/Square.TokenizationBench/CHECKPOINT-RESULTS.md)。

## 安装

```bash
dotnet new install Wuldas.Square.Templates@0.2.0
dotnet new square -n MyApp
dotnet run --project MyApp
```

现有应用升级时，将框架、编译器、平台及扩展包统一升级至 0.2.0。完整用法见[入门指南](../Getting-Started.md)。

## 支持边界

- Windows / Win32 与 Linux / X11 是主要验证的桌面宿主；macOS 也包含在桌面 CI 中。
- Android 仍为 Experimental；arm64 真机和官方 NativeAOT 的既有限制保持。
- 本轮分词优化没有新增生产依赖，没有改动 tokenizer 的公共接口，也没有实现后台或分批高亮。

发布产物由版本标签构建、校验内部依赖和模板包版本，并通过 NuGet Trusted Publishing 发布。正式标签为 `v0.2.0`。
