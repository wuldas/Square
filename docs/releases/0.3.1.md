# Square 0.3.1

Square 0.3.1 是从 `main` 发布的构建与 CI 维护补丁。框架与模板仍为 22 个统一版本的 `Wuldas.Square` / `Wuldas.Square.*` 包，面向 .NET 10；本补丁不引入新的 Canvas 或生产语言服务器功能。

## 构建与验证修复

- **对齐运行时包**：self-contained / NativeAOT 的 .NET runtime、ILCompiler、ILLink 与 apphost 统一选择 10.0.14，覆盖 SDK 中可能更高的 latest patch。保留 SDK 原有的 .NET 10 framework-dependent 运行时基线与 targeting-pack 选择，不将这些概念混作同一个版本。
- **平台测试诊断**：在非 Windows 分支的异常诊断中使用 `surface` 参数，消除 xUnit1026；Windows 的 Auto / Bitmap 两个 case 及断言保持不变。
- **分配测试预热**：补齐完整热路径预热，保留原有 1024 字节门槛及分配检查，没有通过放宽阈值使测试通过。
- **LSP 测试会话**：直接执行与测试构建配置一致的预构建服务器 DLL，避免每个 case 再运行隐式 Debug 构建；持续读取并有界保留 stderr，超时包含请求与错误信息。原 30 秒期限不变，生产 LSP 协议、workspace gate 与缓存策略未因这项 fixture 修复而调整。

## 源码与性能边界

前置主线基线为 `6b3f2f5d84a30cde08a4860d38280ad32eb13032`。其 `src/` tree 与旧 `v0.3.0` 对应源码均为 `e8461e528a5b1fe43d794d14328e53af5f3acf46`；构建元数据、测试 helper 和包版本仍有变化，不能据此称发布物逐字节相同。

本补丁没有新增性能测量或性能优化声明。README 中的 0.3.0 表格及 [2026-11-11 测量记录](../benchmarks/2026-11-11.md)保留原版本、样本与口径，不改称 0.3.1 新测结果。Canvas 与软件呈现功能说明见 [0.3.0 发布说明](0.3.0.md)，其中 best-effort DWM 同步和原生桌面截图 **0/2、limited** 的已知限制继续有效。

## 发布验证与升级

上述前置基线已通过 [CI 43029607139](https://github.com/wuldas/Square/actions/runs/43029607139)（Win32 / X11 / macOS / IDE，LSP 60/60）和 [Android 43029607138](https://github.com/wuldas/Square/actions/runs/43029607138)。这些是基线验证，不代替随后 0.3.1 版本提交与发布产物的门禁。

0.3.1 的版本提交先进入 `main` 并通过 CI，再创建匹配版本标签。正式发布工作流只接受 `main` 已有提交，且标签版本必须与 `Directory.Build.props` 一致；手动 workflow_dispatch 仍只构建验证，不发布。标签指向已经通过 CI 的 `main` 提交。旧 0.3.0 包和公开标签保持原样，不覆盖或移动。

现有应用应将框架、编译器、平台、后端和扩展包统一升级至 0.3.1。安装模板：

```bash
dotnet new install Wuldas.Square.Templates@0.3.1
dotnet new square -n MyApp
dotnet run --project MyApp
```

完整安装与平台边界见[入门指南](../Getting-Started.md)。项目仍处于实验阶段，公共 API 与模板语法可能继续调整。
