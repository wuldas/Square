# 2026-11-11 性能复测（0.3.0 源码）

本页记录 0.3.0 源码在当前机器上的布局动画与 Canvas 综合复测。两套测试都重新构建、串行运行，测量期间不构建、不挂接 DevTools；原始逐目标 JSON 与汇总保留在仓库对应样例目录。

## 源码与环境

- 源码：`origin/main` 提交 `ef6409d634349ebafadc29afcf9eeb4dcee0bfed`，加上 Canvas 后端改进和 Win32 Software 呈现同步；共享 UI、CSS、布局、DOM、编译器与内置 Yoga 沿用该主线提交。版本号 `0.3.0`。
- 机器：Windows 11 专业版 10.0.26300；Intel Core i5-12400F（12 逻辑处理器）；NVIDIA GeForce GTX 1660 SUPER，2560×1440 / 60 Hz。
- 工具链：.NET SDK 10.0.303；本轮 .NET 发布固定使用 runtime / ILC / ILLink / apphost 10.0.14（仓库构建已在 `Directory.Build.targets` 对齐，SDK 默认的 10.0.11 受 GHSA-p3jp-9v83-76w9 影响）；Avalonia 11.3.12；Electron 44.7.2（Chromium 152.0.7977.149）；Flutter 3.47.7 stable（Dart 3.13.5）。
- 所有目标均为 Release / Windows x64。Square 与 Avalonia 为 self-contained；Square 的 Software 与 Direct2D 共用同一发布物。

## 布局与 CSS 动画

工作负载与 [对比示例](../../samples/Square.Sample.PerfComparison)一致：900×1240 客户区，3 组各 240 个方块，分别做 transform、opacity、width 动画，6 秒线性循环；width 改变真实布局宽度。每目标预热 5 秒、测量 30 秒，单轮、固定顺序串行，目标间隔 2 秒。

统计口径与 README 一致：CPU 为测量区间进程 CPU 时间 / 实际经过秒数，100% 表示一个逻辑处理器；Electron 汇总其进程树。内存约每秒采样并取均值，工作集可能重复计入共享页，不含独立 GPU 显存。FPS 是各框架定义的动画/提交计数，不是显示器物理扫描。发布体积为完整可运行目录，含运行时、资源与 XML，仅排除 `.pdb` / `.dbg`。

## Canvas 综合场景

默认单综合场景、固定档位、control-only：1280×800 物理画布、DPR1、每帧 68 条绘制操作，60 帧预热、120 帧测量；六目标各三轮，共 18 个独立进程，不启用桌面捕获。Square 由本轮源码构建；Avalonia、Electron、Flutter 参考应用与 Observer 在逐文件 SHA 确认源码未变后复用当日产物。

三轮范围（CPU / FPS）：Square Software 42.14–45.10 / 59.995–60.025；Square Direct2D 34.98–38.05 / 60.007–60.026；Square Vulkan 38.88–40.17 / 59.999–60.046；Electron 48.16–63.97 / 59.998–60.001；Flutter 42.88–48.08 / 61.557–62.127；Avalonia 57.79–60.31 / 59.946–60.015。

Canvas 的 CPU 是已发现进程树的监控生命周期下界，不是布局测试的 measurement-window CPU；私有内存/工作集按实际相邻完整样本时间加权，不补缺口；FPS 来自 120 个测量事件时间戳的 119 个间隔，是生产端节奏，不是扫描输出。综合场景包含原生渐变、描边与 AA，不表示各框架逐像素等价。

## 限制

- Win32 Software 现在包含每实际提交一次的 DWM 合成节拍等待（best-effort），CPU 与帧节奏包含该成本；这不等于硬件原子翻页或物理扫描无撕裂保证。
- 严格的软件原生桌面截图验证仍为 0/2 通过（CPU 与窗口 DC 正确、桌面捕获为黑），保留为已知限制，未据此下调门槛。
- 单轮布局数据不是统计显著性结论；Flutter 的 N2 只用于呈现波动范围，不用于挑选更好的一次。
