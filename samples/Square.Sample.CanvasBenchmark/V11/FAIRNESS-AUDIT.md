# v11 公平性独立审查

范围：六个 producer（Square 三后端、Electron、Flutter、Avalonia）、Observer 与当前 preflight 工具的只读代码审查。未构建、启动窗口或运行 GPU。**未发现当前 trace 的参数转置、漏掉重复 source-over、按 child 分摊 group alpha 或预建全部动态帧对象的绘制阻断；正式资格仍须落实下面的图像和观测门禁。**

## 正式资格门禁缺口

1. **当前 preflight 的成功退出不能当成语义/画质通过。** [preflight-v11.py:47](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/tools/preflight-v11.py:47>) 仅收集尺寸、opcode 与退出码，没有执行 trace 的 `semanticChecks`、比较六方输入哈希或读取截图 ROI。Square 的实际计数也由绘制后的逻辑 opcode 循环累加（[Square:104](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Square/Program.cs:104>)），只能证明调用计划一致。最小补全：正式采样前读取六方已有截图，执行不透明内部、alpha 重叠、isolated group、真 clip、字体/位置探针，并校验 trace/资产哈希；保留逐项结果，不能仅凭 opcode 相等宣告功能相等。

2. **Observer 的 `status=ok` 不是观测质量合格。** [Marker:147](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/Marker.cs:147>) 会将超长采样间隔、measurement 内无效样本记为 `badCoverage/observerLimited`，但 [Program:202](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/Program.cs:202>) 的状态只看另一份 failures。最小补全：collector 读取这些资格字段，受限观测不进入合格主表；同时保留 missing IDs。实际分母从**第一个看到的 phase2** 到 phase3，分子是 unique IDs（[Marker:109](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/Marker.cs:109>)、[Marker:124](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/Marker.cs:124>)）；若没看到 seq0，不应改称完整120帧耗时，也不能用120替换该分子。

## 限制，需要在结果中披露

3. **nativePrepare/staticPrepare 不是跨框架同一工作边界。** Square 创建的是逻辑 PathGeometry/TextLayout（[Square:157](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Square/Program.cs:157>)）；Direct2D 原生 path 在 Draw 内懒建（[CreatePath:825](<C:/.AA/dotnet-projects/Square/src/Square.Backends.Direct2D/Direct2DRenderContext.cs:825>)），Vulkan mesh 也在 FillPath 内构建/查缓存（[FillPath:334](<C:/.AA/dotnet-projects/Square/src/Square.Backends.Vulkan/VulkanRenderContext.cs:334>)）。Avalonia 则在准备阶段强制 geometry.Bounds，并创建已布局的 TextLayout（[Avalonia:555](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Avalonia/Program.cs:555>)）；Flutter TextPainter 调用 layout（[Flutter:96](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Flutter/lib/main.dart:96>)）；Canvas2D 只能 measureText，不能保存原生 paragraph（[Electron:52](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Electron/renderer.js:52>)）。这些准备成本都仍落入本帧 total；外部主指标不因分栏差异失效。最小处理：CPU 分栏只作各自诊断，不能把 nativePrepare 单列排名为同一种原生创建速度；staticPrepare 内存/时间也标明逻辑准备与原生准备差异。

4. **现有校准工具尚未产生同输入的无 Observer 对照。** [preflight-v11.py:36](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/tools/preflight-v11.py:36>) 的 calibration 始终启动 Observer；semantic 无 Observer 执行的是 verify=1 单帧 fixture，不是配对对照。最小补全：同一 marker-only trace、verify=0 做有/无 Observer 配对进程，再报告原始 CPU/帧诊断和采样扰动。当前捕获确实是每约4ms一次96×8 BitBlt+GdiFlush（[Capture:134](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/Native.cs:134>)）；不是免费观察。进程树 CPU 已诚实标为下界，约100ms采样，measurement 采用边界外包样本（[ProcessTree:156](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Observer/ProcessTree.cs:156>)），不可称精确120帧 CPU。

5. **固定质量资格不能只读 trace 的 qualityComparable。** 主 image 是整数1:1；scaled 与 stroke 已显式受限，处理正确。但 [生成器:75](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/tools/generate-traces.py:75>) 给 mixed-dashboard 默认 true，其 gradient 仍使用各 native 插值；fixture 将 gradient 放在 separateQualityRegions，未给相同内部颜色探针（[生成器:184](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/tools/generate-traces.py:184>)）。最小处理：根据实际 gradient/边缘资格结果决定 mixed 的固定质量参与资格；保留 native 差异，不更换采样或少画。字体注册都使用同目录字节，但“注册成功/非空笔画”仍不等于跨引擎 AA 逐像素相同。

## 已核对无问题的实现

- **动态创建与操作顺序：** 四个 adapter 都只准备当前帧；poly-new/stroke-new/clip-new 重新建 path，text-new 重新建布局或 TextMetrics，随后逐条绘制；没有整帧结果复用。Square 新 text 的 `[size,x,y]` 解析与绘制索引一致（[Square:267](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Square/Program.cs:267>)）；Flutter 4×4 矩阵的列布局对应约定六参数（[Flutter:277](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Flutter/lib/main.dart:277>)）。输入量化为二进制可精确表示的1/16、1/4096，当前 trace 不会因 float/double 解析丢掉这些值。
- **分组透明度真实隔离：** Electron 每组 clear 离屏 canvas、完整重画、pop 时只应用一次 globalAlpha（[Electron:126](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Electron/renderer.js:126>)）；Flutter 用 saveLayer（[Flutter:309](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Flutter/lib/main.dart:309>)）；Avalonia 明确用 PushClip+PushOpacityMask，未用可能分发给 child 的 PushOpacity（[Avalonia:624](<C:/.AA/dotnet-projects/Square/samples/Square.Sample.CanvasBenchmark/V11/Avalonia/Program.cs:624>)）。Square 调用既有真实 layer API；重复 source-over 未被适配器折叠。
- **字体、marker 与 END：** Square FontFace、Electron @font-face、Flutter FontLoader、Avalonia 单字体集合均加载 trace 旁 font.ttf，Avalonia还验证实际 glyph typeface 身份及码点覆盖。四个 adapter 的 phase3 都重画最后 scene 后再画 marker；不把前一画面清空成 marker-only。Observer 检查自有 PID、1280×800/DPI96、tag/CRC/单调序号；输出明确限定为桌面合成观察，不是 scanout/GPU time。实际字体位置、AA、sampler 与 group 探针最终由第1项图像资格证据裁定。
